2026-08-03 (2026q3-ui-uplift): When a user reports a "tailwind/shadcn feel," verify the stack before accepting the diagnosis — arXMCP has no Node at all; the generic feel traced to a self-documented GitHub-Primer palette clone (BAN-15, `app.css:234-241` says so in its own comment), one 1.10x type step, and one container primitive doing every structural job. Naming the *actual* borrowed source made BAN-15 measurable instead of vague. Thesis mistake to avoid next time: on a repo with hard no-build-chain locks, a direction whose distinctiveness depends on a font file or new JS is a direction that probably will not ship — recommend the one that needs nothing new, and say out loud which candidates it is load-bearing on (here: D-1 degrades to "the same page with borders removed" if the type-scale candidate is descoped).
