# Lessons — frontend-uplift-visual-scout

- When the browser-preview toolset is withheld (Bash/Read/Grep/Glob/Write only), rely on the orchestrator's `discover/visual-manifest.md` (live DOM geometry) as `✓ measured` evidence, cross-verify its counts against `grep` on the actual template source (filter out Jinja `{# #}` comment prose, which re-mentions attribute names like `aria-live=` in plain English and inflates naive grep counts), and use `curl` against the live server for route status/timing/fragment bodies — this combination is enough to write a fully evidenced brief with zero PNGs, as long as the brief states the evidence-tier gap plainly instead of fabricating visual impressions.
- arXMCP's `/ui/notebooks/{slug}/papers/{paper_id}/preview` route only resolves for papers added via the "Upload ar5iv HTML" form — papers added via `POST .../papers` (URL paste) have `has_preview=false` and 404 on preview; if a future preflight only seeds via URL paste, the preview route will be un-walkable and that's a seeding gap, not a broken page — don't file it as CRITICAL.
